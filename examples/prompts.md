# 提示词配方

这套模型吃**镜头语言**，不吃形容词。下面每条都按「主体 + 动作 + 镜头运动 + 光线 + 背景」写，
可以直接换主体复用。

## 主图视频（5 秒，配 Viduq2-turbo / Viduq3-turbo）

```
绿色玻璃瓶置于浅色木桌，瓶身缓慢旋转，镜头由中景推至特写，柔和侧逆光，背景虚化
```

```
白色运动鞋放在水泥台阶上，鞋带轻轻晃动，镜头从鞋底环绕到鞋面，午后硬光，背景是灰墙
```

## 带货短视频（10–15 秒，配 全能电商2.0 / Seedance2.0）

```
女装连衣裙挂在衣架上，裙摆被风扇吹起，镜头从中景横移到全身，室内柔光，纯色背景
```

```
坚果包装袋立于木盘中央，坚果从画面右上方落进袋口，镜头轻微俯拍推近，暖色顶光，桌面撒落碎屑
```

## 长片（30 秒，配 Seedance2.5 / MiniMax H3）

分镜要写清节奏，模型会据此切镜头：

```
0-5秒：镜头推近产品包装正面，袋口打开
5-12秒：产品倒进玻璃碗，慢动作特写，碎屑飞溅
12-20秒：人物手持产品在窗边俯身喝，逆光
20-30秒：产品放回桌面，镜头拉远，品牌露出
```

## 通用套路

| 想要的效果 | 加进提示词 |
|---|---|
| 更稳、不乱动 | `镜头固定，仅有轻微推近` |
| 更高级 | 具体材质 + 光源方向：`磨砂玻璃`、`侧逆光`、`柔光箱顶光` |
| 避免手部变形 | `不出现人手` / `产品自转展示` |
| 竖屏短视频 | `--ratio 竖屏`，提示词里别写“横移” |
| 出海 | `--language 英语`，模型按目标语种生成口播 |

**不要写**：「高端大气」「上档次」「爆款」「全网最火」。这些词对应不到画面，模型会自己瞎编。
